## Ep.5 

“ถ้าเขาคือปีศาจ... แล้วฉันคืออะไร?”

คืนนั้น… ไม่เคยจางหายจากหัวจิ้งจอก
กลิ่นเลือดยังตามหลอกหลอน เสียงหัวเราะเยาะของคนทรยศยังคงวนซ้ำ
บอสที่เขาเคารพที่สุด — ตายไปเพราะมือของเขาเอง
เพียงเพราะเขา… เชื่อใจผิดคน

“ฉันมันโง่… และฉันจะไม่ยกโทษให้ใครอีกเลย… แม้แต่ตัวเอง!”

ในห้วงของความสลาย เขาจมลงใน “รอยต่อแห่งกาล” —
ที่นั่นเต็มไปด้วยเศษกระจกพันชิ้น สะท้อนทุกทางเลือกที่เขาไม่เคยเลือก

โลกที่เขาไม่ได้ลงมือฆ่า
โลกที่เขาเลือกถามก่อนแทง
โลกที่เขาเชื่อใจบอส จนรอดพ้นกับดัก

เสียงของตัวเขาเองจากอีกเส้นทางหนึ่งกระซิบมา...

“ยังไม่สาย… ถ้านายกล้าฉีกกฎของ ‘โลกนี้’
รับพลังของฉัน แล้วเปลี่ยนโชคชะตาซะ…”

เขาแตะ “เข็มนาฬิกาแห่งคำสาป” — พลังที่เชื่อมโลกคู่ขนานทุกใบ แต่ต้องแลกด้วย “การลบตัวตนที่แท้จริง”
เมื่อแทงเข็มนั้นเข้าสู่กาลเวลา
เขาไม่ได้เดินย้อนกลับ
…แต่เดิน “ข้าม” ไปยังทุกจักรวาล

🌍 โลกที่ 1
เขาคือคนแปลกหน้าในสายตาบอส
แต่ยังทันได้ช่วยบอสจากการลอบสังหาร —
และยืนมองบอสที่ยังมีชีวิตอยู่ หัวใจอุ่นวาบ… ก่อนจากไปอย่างเงียบงัน

🔥 โลกที่ 2
บอสกลายเป็นพันธมิตรกับแก๊งสารเลว
ความทรงจำของเขา… กลายเป็นของปลอม
เขาต้อง “ฆ่าบอส” เพื่อหยุดจักรวาลนี้ไม่ให้แพร่ขยาย

“ในโลกนี้ นายไม่ใช่บอสของฉัน… แต่นายกำลังทำลายชื่อของเขา”

🪞 โลกที่ 3
ไม่มีจิ้งจอกเลย
แต่มี “ของปลอม” ที่ใช้ชื่อเขาฆ่าผู้บริสุทธิ์
เขาเผาซากตัวตนในโลกนี้ทิ้งไป พร้อมกระซิบว่า

“ถ้าไม่มีความเชื่อ... ฉันไม่ใช่จิ้งจอกเลย”

💀 โลกที่ 4
เขาเป็น “บอส”
และน้องจิ้งจอกอีกคนคือผู้ลอบสังหาร
เขาไม่ต่อสู้… เขานั่งคุยกับ “ตัวเอง”

“อย่าทำผิดแบบฉันเลย…
เพราะถ้านายแทงฉันเมื่อไม่มีคำตอบ นายจะไม่มีวันเป็นอิสระจากมัน”

หลังจากเปลี่ยนปลายทางของทุกจักรวาล
เขาเดินกลับเข้าสู่โลกต้นกำเนิด — เพื่อเผชิญหน้ากับ “บอสที่ยังมีชีวิต”
