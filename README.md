## Ep.6 

บอสยืนอยู่ที่เดิม
เสื้อโค้ทยาวสีดำ ใบหน้าเย็นชาที่เคยอบอุ่น

“นายคือใคร?”
“ฉันไม่เคยมีคนอย่างนายในแก๊งเทียร์เทอร์”

คำพูดนั้นเหมือนฟ้าผ่า
เขาไม่เคยคาดคิดว่า สิ่งที่เขายอมแลกทั้งหมด… กลับทำให้เขาหายไปจากความทรงจำของบอส

“ไม่รู้จักฉันเหรอ…?”
“ฉันคือหมา… ของนายไง”

บอสไม่ตอบ
ไม่มีรอยยิ้ม
ไม่มีคำว่า “เชื่อ” หรือ “ขอโทษ”

จิ้งจอกเข้าใจในวินาทีนั้น
การเปลี่ยนเส้นทางของจักรวาล ทำให้ความสัมพันธ์ทั้งหมด กลายเป็นเรื่องสมมติ

เขาไม่ใช่คนของใครอีกต่อไป
ไม่ใช่ “เงาของบอส”
ไม่ใช่ “จิ้งจอกของใคร”
เขาเป็นเพียง… เงาของความผิดพลาด

“ฉันไม่ต้องการให้นายจำฉันได้อีกแล้ว…”
“ฉันจะสร้างโลกของตัวเอง — ที่ไม่มีการทรยศ ไม่มีเลือด และไม่มี ‘คำว่าเสียใจ’”

เขาปักเข็มนาฬิกาเข้าสู่หัวใจตัวเอง
ทุกจักรวาลหายไปพร้อมเสียงระเบิดเงียบ
เหลือเพียง โลกเดียวที่เขาสร้าง
โลกที่มีแค่เขา… และความเงียบ

🎭 บทส่งท้าย
“ฉันเคยเป็นคนของใครสักคน
ตอนนี้… ฉันเป็นคนของตัวเอง
คนที่ไม่ให้อภัยแม้แต่ตัวเอง
คนที่เชื่อ… แล้วถูกหักหลัง
คนที่รัก… แล้วกลายเป็นฆาตกร”

และในโลกใหม่ที่เขาสร้าง
ไม่มีศรัทธา
มีแต่ “กฎ”
และในกฎนั้น…
เขาคือ พระเจ้าเงียบงันผู้สวมหน้ากากจิ้งจอก
